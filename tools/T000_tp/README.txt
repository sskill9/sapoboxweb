T000 テンプレート: 2026-11-05 / v1.0.0
版の正本はtool-config.jsのreleaseです。

すべてのファイルを展開し、T000index.htmlをブラウザで開いてください。
テンプレート本文、共通タブ、設定、簡易電卓・時計・メモの共通枠を含みます。
HTML/CSS/JavaScriptは同梱ファイルを使います。外部サイト・SNS・配布先リンクには通信が必要です。
配布コピーはダウンロード入口を隠し、ヘッダーから自身のHTMLへ戻ります。

表示設定はブラウザ保存領域、メモは同じタブの一時保存領域を利用します。保存拒否・容量不足・プライベートモード・file://の扱いはブラウザにより異なります。メモは必要に応じてテキスト保存してください。設定はツールごとに分離します。画像などツール固有の入力の永続化はテンプレートに含みません。

コード・配布生成の自動検査に加え、ユーザーによる候補確認と差し替え承認を受けています。すべてのブラウザ・実端末での動作を保証するものではありません。Excelへの貼り付け、ネットワーク切断下の動作、スマホ実機・Safari等の追加検証は未実施です。
版管理・公開と配布の区別・生成方法はVERSIONING.txtを参照してください。変更前のファイルと旧版は管理用バックアップに保持します。

簡易電卓は最大12有効桁の小数表示です。小数の丸めが必要な場合は四捨五入します。結果とコピーは数値のみです。整数部が12桁を超える場合（丸めによる桁上がりを含む）は警告します。非常に小さい非ゼロ値は先頭の小数ゼロを保ち、単に0とは表示しません。計算後に演算子を押すと表示結果から次の計算を始め、数字を押すと新しい式を入力します。式を直接編集した場合は、その式全体を評価します。
